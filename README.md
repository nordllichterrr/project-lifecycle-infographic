# Project Lifecycle Infographic

Интерактивная таймлайн-инфографика цикла создания высшего проекта.

## Stack
HTML · CSS · Vanilla JS

## Run
Открой `index.html` в браузере.

## Deploy
GitHub Pages: Settings → Pages → Branch: main / root.

## Live Demo
https://nordllichterrr.github.io/project-lifecycle-infographic/

## Features
- 7 фаз жизненного цикла проекта
- Sticky progress bar, заполняющийся при скролле
- Stagger-анимации появления карточек
- Hover-glow в цвет фазы
- Полностью адаптивный дизайн
