03 · Инсайт Paper 1 · §VI

Три compounding failure modes

Провал не в «слабой модели», а в трёх слоях пайплайна: retrieval coverage → score discrimination → exposure bias. Reranker не виноват — виноват pipeline.

1°Retrieval bottleneck
2°Score collapse
3°Exposure concentration
6717median GT position
▸ Что именно сломалось
  • Root cause 1: Sentence-BERT оптимизирован под semantic similarity, не под preference prediction — domain mismatch.
  • Root cause 2: MS-MARCO cross-encoder переносится out-of-domain — web passages ≠ movie metadata.
  • Root cause 3: metadata length bias — предметы с 10+ тегами систематически получают выше score.
  • Error taxonomy: 38% genre over-weighting, 26% metadata length, 22% popularity artifacts, 14% шум.
04 · Гипотеза Paper 2 · §4.2

Что если объединить семантику и популярность?

Два провала симметричны: pure content → semantic trap (obscure noise), pure popularity → popularity trap (no personalization). Байесовский компромисс: vMF × Zipf.

vMFsemantic likelihood
Zipfpopularity prior
γ(u)adaptive gate
0.45γ_base
▸ Формула и интуиция
  • Bayes: P(y=1 | u,i) ∝ P(u | i) · P(i).
  • vMF: P(u | i) = C_d(κ) · exp(κ · ⟨u, e_i⟩).
  • Zipf: P(i) ∝ (1 + pop_i)^α.
  • Гейт: γ(u) = γ_base / (1 + 0.05 · min(|H_u|, 20)), γ_base = 0.45.
  • Итоговый score: s(u,i) = (1−γ)·⟨u,e_i⟩ + γ·log(1+pop_i)/max log(1+pop_j).
05 · Метод Paper 2 · §4.2.3

SCIR — Semantic-Collaborative Inductive Gating

Closed-form, training-free, inductive. Recency-weighted семантический центроид + логарифмический popularity prior + user-adaptive gate. Миллисекунды на CPU, без retraining.

1.8 mslatency / user (CPU)
384dSBERT fidelity
0итераций обучения
50kкаталог, full-catalog
▸ Механика
  • Centroid: u = Σ w_i e_i / ‖Σ w_i e_i‖, w_i = 1 + 0.5 · pos(i)/|H_u| (recency).
  • Cold user: u = Encoder(q_text)/‖Encoder(q_text)‖ — onboarding profile.
  • Gate: γ(u) = 0.45 для strict cold; падает с ростом |H_u|.
  • Anti-collapse blend: s_blend = β·s_RRF + (1−β)·s_CE, fallback при std(s_CE) ≤ 1e−5.
  • Full-catalog ranking: |I| ≈ 50k–62k, без FAISS-префильтра.
